# Class 6 Telugu (3L) - Solved Worksheet 3
## Lesson 5: కోతి బుద్ధి (Kothi Buddhi)
**Strictly solved based on SCERT Class 6 Telugu Textbook (3rd Language)**

---

### I. కింది పదాలకు అర్థాలు రాయండి (Word Meanings)
1. **ధనం** = డబ్బు (*Money / Wealth*)
2. **గుడి** = దేవాలయం (*Temple*)
3. **ఊరు** = గ్రామం (*Village / Town*)
4. **గుంపు** = సమూహం (*Group / Crowd / Herd*)
5. **పండు** = ఫలం (*Fruit*)

---

### II. కింది వెబ్ చార్ట్ పూర్తి చేయండి: "ఊరు" లో ఉండేవి (Web Chart: Things in a Village)
- **గుడి** (*Temple*)
- **బడి** (*School*)
- **చెరువు** (*Pond / Lake*)
- **పొలం** (*Agricultural Field*)
- **చెట్లు** (*Trees*)
- **ఇండ్లు** (*Houses*)

---

### III. 'తి' తో అంతమయ్యే పదాలు (రహస్య క్లూస్ ఆధారంగా - Textbook Pg 58)
1. **భర్త** = **పతి** (*Husband*)
2. **ఎక్కువగా చేస్తే** = **అతి** (*Excessive*)
3. **సన్యాసి** = **యతి** (*Ascetic / Sage*)
4. **బుద్ధి** = **మతి** (*Intellect / Wisdom / Mind*)

---

### IV. కింది పదాలలో ఒత్తులు సరిచేసి సరైన పదాలు రాయండి (Spelling Corrections with Vattulu)
1. కొమ ➔ **కొమ్మ** (*Branch*)
2. మధ్యాహ్నం (మధ్యానం) ➔ **మధ్యాహ్నం** (*Afternoon*)
3. పండులు / పంలు ➔ **పండ్లు** (*Fruits*)
4. చెటులు / చెటు ➔ **చెట్లు** (*Trees*)
